Sub:- Over heated wire test for FSDS fitted in IR AC Coaches as per specification no. RDSO/2008/CG-04/(Rev-06).

Clause 11.4 of RDSO specification no. RDSO/2008/CG-04/(Rev-06) contains the proforma for testing of automatic smoke/ fire detection system during installation and commissioning on a designated coach.

The proforma contains following tests which are to be carried out during commissioning
i. Smoke detection test for each sampling point.
ii. Checking of the threshold value.
iii. Airflow monitoring test.
iv. Testing of Brake application.
v. Hot wire test.

During a recent fire incidence, the FSDS system was found not properly installed which indicates that installation & commissioning was carried out without completing all the tests as mentioned in the proforma.

Further, Hot wire test is an important test for testing of the FSDS system by simulating electrical fire and accordingly Zonal Railways must ensure that all the test as per clause no 11.4 of RDSO spec no. RDSO/2008/CG-04/(Rev-06) including Hot wire test are carried out during installation & commissioning of FSDS system on designated coaches.
