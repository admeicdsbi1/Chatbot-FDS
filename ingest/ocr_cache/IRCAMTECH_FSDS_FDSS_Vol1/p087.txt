### 6. TCMS CONVERTER LED INDICATIONS

**FDS COMMUNICATIONS LED**

| | | | | | | |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | **TCMS** | Green LED | D6 | while transmitting D6 green LED glows once in a second | Healthy condition | Power supply to the TCMS converter card |
| 2 | | Blue LED | D7 | while receiving D7 blue LED glow, If D7 long indicates waiting for response if short indicates device communicating with TCMS. | Healthy condition | 1) If D7 long indicates waiting for response 2) if short indicates device communicating with TCMS. |
