WSP Fault Code Trouble Shooting

| Fault | Troubleshooting |
| :--- | :--- |
| **Failure of Relay Disconnector** | |
| 1.0 | For Axle 1 | ❖ Check Dump Valve connections. |
| 2.0 | For Axle 2 | ❖ If connections are okay, JOP Card can be faulty. |
| 3.0 | For Axle 3 | ❖ Replace the respective JOP card and restart the system. |
| 4.0 | For Axle 4 | |
| **Short circuit / open circuit or no signal of speed sensor (TG)** | |
| 1.1 | For Axle 1 | ❖ Check the connections of the speed sensor, if found short/ open circuit, fix it. |
| 2.1 | For Axle 2 | ❖ If connections are okay, check gap between the phonic wheel and speed sensor, it should be between 0.9mm to 1.4mm. If abnormal gap is detected, correct it. |
| 3.1 | For Axle 3 | ❖ If everything above is okay, JFP card can be faulty. |
| 4.1 | For Axle 4 | ❖ Replace the JFP card and restart the system. |
| **Short circuit of exhaust valve (EX) / wires short** | |
| 1.2 | For Axle 1 | ❖ Check if the Dump Valve Exhaust coil is shorted. If it is, replace the Dump Valve. |
| 2.2 | For Axle 2 | ❖ If the coil is fine, look for any shorted wire and fix it. |
| 3.2 | For Axle 3 | ❖ If the coil and wiring are okay, re-check the system if problem persists, replace the respective JOP Card. |
| 4.2 | For Axle 4 | |
| **Open circuit of exhaust valve (EX) / wires broken** | |
| 1.3 | For Axle 1 | ❖ Check if the Dump Valve Exhaust coil is open. If it is, replace the Dump Valve. |
| 2.3 | For Axle 2 | ❖ If the coil is fine, look for any open wire and fix it. |
| 3.3 | For Axle 3 | ❖ If the coil and wiring are okay, re-check the system if problem persists, replace the respective JOP Card. |
| 4.3 | For Axle 4 | |
| **Failure of exhaust valve (EX) switch** | |
| 1.4 | For Axle 1 | ❖ JOP card can be faulty. |
| 2.4 | For Axle 2 | ❖ Replace the respective JOP card and restart the system. |
| 3.4 | For Axle 3 | |
| 4.4 | For Axle 4 | |
