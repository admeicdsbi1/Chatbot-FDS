### Technical Descriptions
*   **Brake Chopper Resistor Configuration:** Each Motor Coach has two independent Brake Chopper Resistors housed in a single cubicle.
*   **Mounting:** Under-slung mounted.
*   **Function:** Limits over-voltages in DC link capacitors during abnormal conditions or transients.
*   **Over-voltage Causes:**
    *   Non receptive OHE during regeneration.
    *   Transient load conditions.
*   **Operational Logic:**
    *   LICC measures DC Link voltage.
    *   If voltage exceeds set limit, BCH IGBT module is switched ON (fixed duty cycle).
    *   Excess voltage is dissipated in the Brake chopper resistor.
    *   BCH IGBT module is switched OFF only when DC link voltage returns to regular operating value.
