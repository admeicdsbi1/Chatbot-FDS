### ACU Modules/Sections
The Auxiliary Converter Unit (ACU) consists of the following modules/sections:
*   Input section
*   Line converter
*   3-phase inverter section
*   3-phase sine filter
*   DC converter
*   Output section
*   Shed supply section
*   Controller Module
*   Cooling system

### Input Section Technical Details
*   **Source:** Input is taken from the independent auxiliary secondary windings of the main transformer.
*   **Components:** Consists of input fuse and input isolation contactor.
*   **Input Fuse Purpose:** To protect the converter from over current.
*   **Input Isolation Contactor Purpose:** Used to isolate the Converter from Input in case of any failure occurred inside the converter.
*   **Pre-charging Circuit:** Used to charge the DC link capacitors during initial start-up condition.
